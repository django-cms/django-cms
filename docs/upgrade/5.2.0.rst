How to upgrade to 5.2.0
***********************

Before upgrading, back up your database and uploaded media and review the
:ref:`backward-incompatible changes <upgrade-5.2-backward-incompatible>` below.
TODO: note any minimum Django version or removed APIs.

Upgrade django CMS and ensure that your environment contains a compatible
Django version::

    python -m pip install --upgrade "django-cms==5.2.0" "Django>=X.Y"

Then apply migrations, collect static files, and run the django CMS checks::

    python manage.py migrate
    python manage.py collectstatic --noinput
    python manage.py cms check

in a staging environment before deploying. TODO: add any release-specific
